## Page 2 — Specifications

### Operating System & Processor

| Field | Value |
| --- | --- |
| O.S. | Android 13 |
| Processor | Quad-core A53 2.0 GHz |
| Memory | RAM: 2 GB, ROM: 16 GB; RAM: 3 GB, ROM: 32 GB (optional) |

### Display

| Field | Value |
| --- | --- |
| Main Display | 5" Display 480 × 854, (720 × 1280 optional) |
| Customer display | 128 × 32 mono display (optional) |
| Customer display (top) | 2" top color non-touch screen (optional) |

### Button & Network

| Field | Value |
| --- | --- |
| Button | PWR button, Vol+/− button |
| Network Connection | 4G / 3G / 2G; Bluetooth 5.0; Wi-Fi: IEEE 802.11 a/b/g/n/ac 2.4 GHz / 5 GHz |

### Camera

- No front camera (0.3 MP FF optional)
- Top 0.3 MP FF camera
- No rear camera (5 MP AF optional)
- The front and top cameras cannot be supported at the same time
- Front + Rear or Top + Rear

### Scanning

Camera decoding, supporting 1D / 2D barcode.

### Payment

- Magnetic stripe card
- IC Card
- Contactless Card

### Thermal Printer

| Field | Value |
| --- | --- |
| Media roll size | 40 mm |
| Media width | 58 mm printing paper |
| Resolution | 203 dpi (8 dot/mm) |
| Print speed | 60 ~ 70 mm/s |
| Barcode support | Support 1D / 2D bar code printing |

### Audio

Speaker

### Positioning

GPS, A-GPS, BEIDOU, GLONASS, Galileo

### Slot

| Field | Value |

| Slot option 2 (optional) | 1 eSIM + 1 Nano SIM2 + 1 SAM1 + 1 SAM2 + 1 MicroSD |
