## Appearance and Buttons

The DT50P is a handheld UHF RFID mobile computer with a pistol-grip handle and built-in RFID reader antenna.

**Front of device:** Scanner LED, System LED, Receiver, Front Camera, Touch Screen.

**Side buttons:**
- Left side: PTT Custom Button, Scan Button.
- Right side: Volume Up + / Down −, Scan Button.

**Top of device:** Loudspeaker.

**Back of device:** Handle, Battery Cover Locker.

**Back / bottom further:** Fast (charging contacts), Scan Engine, Camera, RFID Reader Antenna.

**Connector:** USB / Charging Port.

## Unpacking Instructions

### SIM Card, TF Card Installation Method

Use the silver tab on the top-left corner to pull out the SIM card/TF card holder. Place the SIM card and TF card into the respective slots (as shown). Push the holder in completely.

- TF Slot
- Card Tray
- Nano SIM Slot 1
- Nano SIM Slot 2

Note: SIM card 1 and 2 are Nano SIM cards.

### Battery Installation

1. Install the battery in the direction as shown.
2. Place the back cover fully, then push the lock buckle to the right (lock).

NOTE: Overexertion should be avoided when installing or removing the battery.

## Power Options

- **Power on:** press and hold the power button until the device vibrates.
- **Shutdown:** press and hold the power button until the shutdown prompt appears; click "Shutdown".
- **Forced restart:** press and hold the power button for 10 seconds. Do not press the shutdown prompt — the device will restart.

Note:
1. When the device acts as a SLAVE connected to a PC, the "This device" option will be automatically selected.
2. When the device acts as a HOST connected to other devices, the "Connected device" option will be automatically selected.

## USB Data Cable Charging

Connect one end of the USB cable to the adapter and the other end to the device. A charging cradle is recommended for convenient charging.

## PC Connections

Connect the device to the PC using the USB cable provided. If an additional driver is required, the PC will automatically download it from the internet. Once the USB port has been connected, drag the notification bar from the top of the screen to display the USB setting interface.

1. Tap to activate the developer menu shown (Figure 1).
2. Tap to activate the USB preference menu shown (Figure 2).

**Figure 1 — USB Preferences (toggled options shown in the source):**
- USB controlled by Connected device / This device / Use USB for File Transfer / USB tethering / PTP / No data transfer
- Selecting an option sets the matching USB behavior (e.g., "Select this option to access device storage." / "Select this option to share the device data with the computer." / "Choose this option to transfer images." / "Choose this option for charging the device.")

**Figure 2 — Developer options (toggles shown):**
- Automatic system updates: On
- USB debugging
- Wireless debugging
- Bug report shortcut: On (Click three times to switch on debug mode)

On a Windows PC, go to "My Computer" and click "Removable Disk" to view and transfer device data.
