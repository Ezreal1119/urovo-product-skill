### Operating System & Processor

| Field | Value |
| --- | --- |
| Model Name | i5300 |
| O.S. | Android 13 |
| Processor | Quad-core A53 2.0 GHz |
| Memory | RAM: 2 GB, ROM: 16 GB |

### Display & Button

| Field | Value |
| --- | --- |
| Display | 3.5" Touch display, 320 × 480 |
| Button | 16 keys keyboard with back light |

### Network Connection

| Field | Value |
| --- | --- |
| Network | 4G / 3G / 2G |
| Bluetooth | 5.0 |
| Wi-Fi | IEEE 802.11 a/b/g/n/ac 2.4 GHz / 5 GHz |

### Camera

- No front camera (0.3 MP FF optional)
- Top 0.3 MP FF with flash light
- No rear camera (5 MP AF optional with flash light)
- The front and top cameras cannot be supported at the same time
- Front + Rear or Top + Rear

### Scanning

Camera decoding, supporting 1D / 2D barcode.

### Payment

- Magnetic stripe card
- IC Card
- Contactless Card
