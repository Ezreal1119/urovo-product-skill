## Product Highlights

**Four sizes (overview: 1.54 / 2.13 / 2.66 / 4.2 inch)** · **2.4 GHz active e-paper** · **F24A7 base station** · **Cloud or local MQTT** · **NFC tap-to-update**

## Key Features

### End-to-end ESL ecosystem

The English overview positions tags, base stations, and a cloud/local management platform as one stack. Tag specs add optional base-station-local management without a separate server, plus phone-app update (NFC on the 2.1-inch spec advantages; Bluetooth on the 4.2-inch spec advantages).

### Four display sizes

Overview product matrix: 1.54-inch, 2.13-inch, 2.66-inch, 4.2-inch, four-color (black/red/white/yellow) e-paper, LED locate, templates with QR/barcode/images. A synchronized spec for the 1.54/1.6-inch size is not in the Hub yet.

### Operations platforms

Overview names an Operation Management Platform (org, templates, logs) and a Smart Digital Labeling Platform (store, products, price-tag push, blink tasks, binding, base stations). Deployment: POE base station, 16 s tag activation, batch bind “thousands in two hours.”
