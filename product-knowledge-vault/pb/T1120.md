## Product Highlights

**4-inch industrial** · **Direct thermal / thermal transfer** · **203 mm/s (8 ips)** · **104 mm print width** · **USB + Ethernet + serial**

## Key Features

### Industrial-grade construction
Metal chassis with an aluminum-alloy print mechanism. Foldable side cover and large viewing window.

### Connectivity
USB 2.0, USB Host 2.0, Ethernet, and serial; optional Bluetooth and Wi-Fi.

### Languages and memory
TSPL, EPL, EPL2, ZPL / ZPL II, and DPL (slide 2 prints ZPLI). 128 MB SDRAM and 128 MB Flash.

## Key Differentiator

Industrial 4-inch desktop printer positioned above the D8100 Plus class in size (439 × 260 × 335 mm, 12.8 kg) and rated speed (203 mm/s at 203 dpi).
