# RFIDWedge User Manual

**Source type:** multi-product software operation manual (platform-wide).

**Paths:**
- Markdown: `_shared/operations/rfid-wedge-user-manual_202608152156/RFIDWedge_User_Manual_v21.md`
- Original: `_shared/operations/rfid-wedge-user-manual_202608152156/RFIDWedge_User_Manual_v21.pdf`

**Scope:** Applies platform-wide to UROVO Android devices with RFID capability. RFIDWedge is a no-code RFID input tool that delivers tag data into any foreground application without integration (the RFID equivalent of ScanWedge), enabling fast deployment and flexible data control.

**Version:** V21 (dated November 14, 2023).

## Query Guidance

Use this source for questions about RFIDWedge configuration: enabling the wedge, output mode/keyboard emulation, tag data formatting, filter rules, and app-pairing. It is the production-grade RFID input path (vs. RFID-Demo, which is for demonstration). Note the RFG91 product spec also references RFIDWedge as the no-code input tool.
