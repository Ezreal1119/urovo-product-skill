# Honeywell Extended FlexRange™ EX30 2D Scan Engine

**Source type:** multi-product reference (portfolio-wide, for UROVO barcode-scanning devices).

**Paths:**
- Markdown: `_shared/scan-engines/honeywell-ex30-scan-engine_202608161732/Honeywell-Scanner-EX30-Specs.md`
- Original: `_shared/scan-engines/honeywell-ex30-scan-engine_202608161732/Honeywell-Scanner-EX30-Specs.pdf`

**Scope:** Honeywell **Extended FlexRange EX30** 未解码 2D 扫描引擎（自动对焦），读距 **10 cm 到 20 m [4 in 到 66 ft]**；近距宽角读距 42°，最远 20 m。13 × 30.5 × 22.2 mm、23.5 g，MIPI 或 parallel 接口；电气接口与 N670X/N660X/N360X 兼容；可配 Gen7 DB Decoder Board 接入非 OS 设备。

**适用产品（UROVO 条码扫描设备）：** 任何条码识读设备——手持终端、平板、可穿戴扫描器、移动终端、sled（与 N670X/N660X/N360X 同尺寸替代场景）。具体可配机型需确认硬件尺寸与接口兼容性。
