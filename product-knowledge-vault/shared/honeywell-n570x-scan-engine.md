# Honeywell N570X Series Compact Undecoded 2D Scan Engines

**Source type:** multi-product reference (portfolio-wide, for UROVO barcode-scanning devices).

**Paths:**
- Markdown: `_shared/scan-engines/honeywell-n570x-scan-engine_202608161732/Honeywell-Scanner-HS7-Specs.md`
- Original: `_shared/scan-engines/honeywell-n570x-scan-engine_202608161732/Honeywell-Scanner-HS7-Specs.pdf`

**Scope:** Honeywell **N570X Series** Compact 未解码 2D 扫描引擎，包括 **N5703SR（Standard Range）** 和 **N5701HD（High Density）** 两个光学型号。8.1 × 21.6 × 10.4 mm，N5703SR 2.1 g / N5701HD 1.9 g，MIPI 接口。1 Mpx global shutter，60 fps，运动容差 6 m/s。SR 适合物流（Code 39 至 0.86 m + 白色 LED + 红色激光十字准星），HD 适合零售/医疗近距离识读（最小 2 mil 1D / 4 mil 2D + 暖白 LED + 绿色 LED 点瞄准）。电气向后兼容 N670X/N660X/N4603/N360X（同连接器）。

**适用产品（UROVO 条码扫描设备）：** 紧凑移动设备（平板、可穿戴扫描器、移动终端、零售/医疗配件、配送/取件/现场服务）。
