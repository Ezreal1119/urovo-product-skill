## Content Scope

- Configure a prototype, then **Export** (Upload to UMS, Generate barcode, Export to local) or **Import** (scanner QR, camera QR, local TXT).
- Local export directory `/sdcard/UStage`; example files `ustage_00000000.pdf` / `.txt`.
- UMS Configure Management silent deploy (group or SN release); progress `executed / total`.
- Synchronizable modules: Scanner, ScanWedge, System settings, Special system settings, Keymap, Enterprise Desktop, SMB/FTP/HTTP file download, RFID Config, UBrowser Config — item lists in §3.
- Not a live hardware spec. Product user guides that mention U Stage remain device UI samples; this manual is the dedicated software source.

## Query Guidance

Use this source for how U Stage staging files are created, exported, imported, and which setting groups can be synchronized. Prefer it over brief U Stage chapters inside individual device user guides when the question is about the app itself. Availability of RFID, scanner, or UMS binding still depends on the device.
