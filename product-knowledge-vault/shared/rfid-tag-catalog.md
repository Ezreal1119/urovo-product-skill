# 勤业物联 RFID 电子标签热销款目录

**Source type:** multi-product reference (portfolio-wide, for UHF RFID reader products).

**Paths:**

**Scope:** 勤业物联（Qinye）出品的 UHF RFID 电子标签**热销款目录**——按标签形态分类（超高频不干胶标签、织唛标签/纸质吊牌、柔抗标签、ABS 抗金属标签、卡片标签、PCB 抗金属标签）列出 DTB-* 型号、天线/成品尺寸、芯片，并附**超高频芯片对照表**（Alien Higgs / Impinj Monza / Impinj M700/M800 / NXP UCODE / 复旦 Fudan 的 EPC 容量、用户存储、读写灵敏度）。

**适用产品（UHF 读写设备）：** FR1000、FR7000 Series、RFG91、DT50P、DT50P Lite、DT610、DT610 Pro 等 UHF RFID 读写器/手持机。

## Query Guidance

用此来源回答「DTB-* 标签的尺寸/芯片/材质形态」以及「各厂商 UHF 芯片的 EPC 容量、用户存储、灵敏度对比」问题。配合 UROVO 读写器的 UHF 频段（860–960 MHz）使用。
