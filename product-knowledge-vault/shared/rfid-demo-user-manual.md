# RFID-Demo User Manual

**Source type:** multi-product software operation manual (platform-wide).

**Paths:**
- Markdown: `_shared/operations/rfid-demo-user-manual_202608152156/RFIDDemo_User_Manual_V25.md`
- Original: `_shared/operations/rfid-demo-user-manual_202608152156/RFIDDemo_User_Manual_V25.pdf`

**Scope:** Applies platform-wide to UROVO Android devices with UHF/HF RFID capability. RFID-Demo is a built-in demonstration application for reading and writing RFID tags (UHF EPC C1G2 and HF ISO 15693/14443) without third-party integration.

**Version:** V25 (dated November 1, 2023).

## Query Guidance

Use this source for questions about the RFID-Demo application: how to open it, tag reading/writing workflow, tag data fields (EPC, TID, RSSI), inventory/scan modes, and firmware compatibility. It is a demo tool, not a production integration API — do not treat it as a substitute for RFIDWedge or the RFG91/DT-series SDK for production capture workflows.
