# 勤业物联 RFID 电子标签应用选型表

**Source type:** multi-product reference (portfolio-wide, for UHF RFID reader products).

**Paths:**
- Markdown: `_shared/rfid-tags/rfid-tag-application-selection_202608152235/勤业-RFID电子标签应用选型表（热销款）.md`
- Original: `_shared/rfid-tags/rfid-tag-application-selection_202608152235/勤业-RFID电子标签应用选型表（热销款）.pdf`

**Scope:** 勤业物联（Qinye）出品的 UHF RFID 电子标签**按行业应用选型表**——按 8 大行业（鞋服 / 食品 / 3C / 物流 / 医疗 / 新能源 / 汽车 / 金融）给出推荐标签型号（DTB-* 系列）、天线尺寸、成品尺寸与芯片（以 Impinj M730/M830 为主，抗金属/PCB 标签用 NXP UCODE 8/9xe）。

**适用产品（UHF 读写设备）：** FR1000、FR7000 Series、RFG91、DT50P、DT50P Lite、DT610、DT610 Pro 等 UHF RFID 读写器/手持机——回答「某行业/场景该选哪种 RFID 标签」的选型问题。

## Query Guidance

用此来源回答「某行业（如鞋服/物流/医疗）应该配哪种 RFID 标签」的选型问题。表中型号（DTB-C40M 等）与芯片（Impinj M730/M830、NXP UCODE 8）是标签侧规格，配合 UROVO 读写器的频段（860–960 MHz）使用。
