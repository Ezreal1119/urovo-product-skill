# Zebra SE58 Extended Range Scan Engine

**Source type:** multi-product reference (portfolio-wide, for UROVO barcode-scanning devices).

**Paths:**

**Scope:** Zebra **SE58 Extended Range Scan Engine**，搭载 **IntelliFocus™** 智能对焦，工作范围 **<2 in./5 cm 到 >105 ft./32 m**（行业最宽），100 mil Code 39 至 107 ft、55 mil QR 至 24 ft。**1 MP 近距固定对焦 + 2 MP 远距变焦** 双传感器；绿色激光瞄准（520 nm，带宽十字）比红色瞄准高 7 倍可见度。10.6 g 重量 + 10.6 mm 高度，比竞品轻 50%+、小 18%¹。

**SDL 软件解码**：直接用主机 CPU（Qualcomm/MediaTek/NXP + Android/Linux），无需硬件解码器；省空间/功耗/成本/电池循环；用 Android Camera Native API 兼容未来 Android 版本。

**适用产品（UROVO 条码扫描设备）：** 仓储、运输与物流、零售——叉车作业（不到座位）、零售上架（不爬梯）、仓库地面/货柜顶部（不蹲）、院子高空集装箱（不移动）等超远距扫描场景。
