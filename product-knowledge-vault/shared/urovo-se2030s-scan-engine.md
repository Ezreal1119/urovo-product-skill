# UROVO SE2030S 扫描引擎规格参数

**Source type:** multi-product reference (portfolio-wide, for UROVO barcode-scanning devices).

**Paths:**

**Scope:** UROVO 优博讯自研 **SE2030S** 2D 扫描引擎规格参数（中文）：1280×1080 图像分辨率、白色 LED 照明、红色十字激光瞄准、60 fps；视场角水平 38° / 垂直 33°；旋转 360°、上下倾斜 ±60°、左右偏移 ±60°；最小打印对比度 20%、1D 最小解析度 ≥3 mil；识读景深 13 mil 100% UPC-A 55–600 mm、20 mil QR Code 30–530 mm。支持码制覆盖 Linear、2D Stacked、2D Matrix、Postal、OCR（OCR-A/B、E13B MICR）。

**适用产品（UROVO 条码扫描设备）：** 所有搭载 SE2030S 扫描引擎的 UROVO 手持终端/移动终端（具体型号需确认硬件集成）。
