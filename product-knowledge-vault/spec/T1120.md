## Overview

T1120 is a 4-inch industrial barcode printer (direct thermal / thermal transfer) with a metal chassis and aluminum-alloy print mechanism. The current local source is a two-slide EN product brief.

## T1120 printing (slide 2 T1120 column)

| Parameter | Specification |
| --- | --- |
| Print method | Direct Thermal / Thermal Transfer |
| Print language | TSPL, EPL, EPL2, ZPL / ZPL II (slide 1) or ZPLI (slide 2) — see Hub |
| Resolution | 203 dpi (8 dots/mm) |
| Max. print speed | 203 mm/s (8 ips) |
| Max. print width | 104 mm (4.1") |
