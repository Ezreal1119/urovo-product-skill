# FR2000 Desktop RFID Reader Brochure

FR2000
Desktop RFID Reader
Exceptional Performance
Equipped with the cutting-edge Impinj E710 chip and proprietary algorithms, it achieves an
exceptional read accuracy of up to 99.9%.
Anti Cross-Read
Robust metal casing prevents signal leakage, significantly improving reading
accuracy while preventing cross-reads.
Versatile Power Options
Supports USB power supply, with optional PoE supply. Data transmission and power
supply can be easily achieved with a single USB Type-C cable or RJ45 Ethernet,
effectively reducing deployment and maintenance costs.
Flexible Connectivity Options
Standard Type-C USB 2.0 interface, with Bluetooth 5.0 and RJ45 Ethernet connectivity.
It can seamlessly connect and communicate with devices running different operating
systems such as Windows, Android, and iOS.
Full-Frequency UHF Tag Read & Write
Supports multiple operating frequencies and the ISO 18000-6C (EPC C1G2)
international protocol, meeting the requirements for full-frequency UHF tag
reading and writing.
Dual Reading Feedback Modes
Built-in LED indicator and buzzer provide real-time reading feedback, preventing
tags read miss.
