Chapter 1 Introduction 
1.1 About K180 
K180 is an efficient, flexible and convenient wireless barcode scanning device. K180 
uses Bluetooth as the transmission medium, which can transmit data to the host over 
long distances, allowing users to easily scan barcodes at different locations. K180 is 
committed to providing an excellent user experience and provides a new barcode 
scanning solution for application scenarios such as industrial production, warehouse 
management, logistics distribution or retail, easily meeting the scanning needs in different 
scenarios. 
1.2 About this manual 
The manual mainly introduces the system settings, communication settings, barcode 
parameter settings and setting methods of K180. By reading the setting barcodes in the 
manual, you can enable the corresponding functions. The setting code marked with 
"default" represents the default setting of K180. The default settings provided by K180 
are suitable for a variety of application scenarios. Users can use them out of the box and 
generally do not need to set them separately.

2.2 Setting method 2: Configuring software 
2.2.1 Single setting code setting 
Use the configuration software to send setting instructions through the corresponding 
communication interface to complete the function configuration. 
Command format: ABCXYZTV 
Where: ABC - primary identification, only 3 letters or numbers 
XYZ - sub-id, only 3 letters or numbers 
T - command type, "!" represents setting, "?" represents query value, "^" represents 
query configurable range 
V - Set parameter value (used when command type is "!"), which may be a data 
string 
2.2.2 Multiple setting codes setting 
Users can set multiple functions at the same time. Send multiple commands through the 
configuration tool, set a separator (, English comma) between each command, and set 
the end character (; English semicolon) at the end to complete the setting. 
It should be noted that multiple setting code settings can also be set via Data Matrix 
barcodes.

the vibration time of the vibrator. 
1. Run the configuration software and insert the device. 
2. Select "Online Device" and connect the device, select "More Functions", and 
On "Command Debugging". 
3. Send the command: “VIBENA!1,VIBDUA!500;”

3.2 Scan mode settings 
3.2.1 Scan Mode 
Level trigger mode: Press and hold the device scan button to start code reading, 
and stop code reading after the code is successfully read or the button is released. 
Pulse trigger mode: Press the device scan button to start reading the code, and 
stop reading the code after the code is successfully read or the code reading 
duration is reached. 
Continuous mode: Continuous decoding, press the device scan button to switch 
between the reading state and the stop state. 
Induction mode: The device starts reading the code after detecting image changes, 
and stops reading the code after the code is successfully read or the reading 
duration is reached. 
Batch code reading mode: Press and hold the device scan button, the device 
starts to read the code, release the scan button to stop reading the code, and the 
device will continue to read the code as long as the scan button is not released. The 
device will display a success prompt and output the barcode information when the 
code is successfully read. The same barcode can only be read once in one reading 
process. 
Pre-aiming mode: After the pre-aiming mode is turned on, the focus laser is always 
on, indicating the current aiming position of the device. Press the scan button, the 
device starts to read the barcode, and stops reading the barcode when the scan 
button is released or the barcode is read successfully. 
Induction - Level Trigger Mode: When the device is in the induction mode, press 
the scan button to switch to the level trigger mode. If the scan button is not pressed 
after the timeout, it will switch back to the induction mode. The timeout period is 5 
seconds by default, and the range is 100 - 3600000 milliseconds. (The induction 
mode must be turned on first)

7.8 Data Encapsulation 
Through data encapsulation, users can verify data packets on the application side to 
ensure that complete and accurate data is obtained. 
It should be noted that after enabling data encapsulation, users need to actively parse 
the data packet to obtain the original data. 
There are two formats for data encapsulation: encapsulation format 1 and encapsulation 
format 2 
Packaging format 1: [HEAD + LEN + TYPE] + DATA + [LRC] 
Packaging format 2: [HEAD + LEN + TYPE + CODE_ID] + DATA + [LRC] 
HEAD: data header, fixed to 0x0200, double-byte, big-endian 
LEN: Barcode data (DATA) length, double-byte, big-endian, value range is 0 ~ 65535 
TYPE: Encapsulation format, format 1 is 0x36, format 2 is: 0x3B, single byte 
CODE_ID: barcode serial number, refer to Appendix - Barcode Information 
DATA: barcode data 
LRC: Check character, generated by the LRC check algorithm: LRC = 0xFF ^ LEN ^ 
TYPE ^ DATA (^ represents XOR operation), single byte 
Disable data encapsulation (default) 
 
 
Enable data encapsulation and use encapsulation format 1
