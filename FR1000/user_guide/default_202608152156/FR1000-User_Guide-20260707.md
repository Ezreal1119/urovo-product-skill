1.Introduction
1.1 Product Overview
This manual provides information and instructions for operating the
RFID Reader/Writer. The device is Android, with no built-in screen, if you
need to demonstrate, you can connect external devices such as monitors,
keyboards and mice to operate.
The RFID Reader/Writer features eight read/write antenna interfaces,
four network antenna interfaces, one DC interface, three USB interfaces,
one RJ45 interface, one RS232 interface, one GPIO interface, one HDMI
interface, one MicroUSB interface for debugging, and a reset button.
