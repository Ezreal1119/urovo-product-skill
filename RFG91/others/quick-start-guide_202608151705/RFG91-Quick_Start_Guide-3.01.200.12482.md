## Overview

The RFG91 UHF RFID sled has the following physical indicators and parts:

- Scanner LED
- Battery LED (left side)
- Decode status LED
- System LED
- Wireless / signal indicators: Scan window; Charging (Pogo pin); Low Battery, Charging, Bluetooth connected; Blue (Bluetooth searching); Green (RFID reading)
- Mode LED: Green (RFID reading); Yellow (RFID and Scan at the same time); Blue (Bluetooth searching); off (NFC switch on or scan switch to scan engine)

## Indicator Description

### Battery LED

| Status | Description |
| --- | --- |
| Red blinks slowly | Battery less than 10% (low battery) |
| Red blinks | Low battery level 20% |
| Orange | Charging (21%–70%) |
| Green blinks | Fully charged (95%–100%) |
| Green | Disconnected |

### Bluetooth LED

| Status | Description |
| --- | --- |
| Blue | Bluetooth connected |
| Blue blinks quickly | Connecting (searching / scanning to scan) |
| Off | Disconnected (searchable) |

### Mode LED

| Status | Description |
| --- | --- |
| Green | RFID reading |
| Yellow | RFID and Scan at the same time |
| Off | Long press to switch to scan engine |

### RFID Reading

| Status | Description |
| --- | --- |
| Green blink | RFID reading successfully |
| Off | Not reading |
| On | Scan window active |

## How to Install Battery

### Installing the Battery

1. Press the battery release buttons on the lower part of the handle.
2. Turn the battery to insert.
3. Turn the battery to lock; the battery cover fits the lock position.

### Removing the Battery

1. Turn the battery lock to unlock.
2. Reverse the battery for removal.

Note: turn the battery back button to lock; pull the battery latch button to lock.

## Button Introduction

| Button | Status / Action | Description |
| --- | --- | --- |
| Power Button | Long press 2 s | Turn on/off the device |
| Power Button | Power on (already powered) | Power indicator lights 1 s: Red (1%–20%), Yellow (21%–70%), Green (71%–100%) |
| Mode Button | Long press 1 s | Switch RFID / SCAN |
| Bluetooth Button | Long press 3 s | Enter pairing mode |
| Bluetooth Button | When connected, long press 3 s | Enter pairing mode |
| Bluetooth Button | Bluetooth switch off, long press 3 s | Enter pairing mode |
| Trigger Key | Press / release in RFID mode | RFID reading |
| Trigger Key | Scan mode | Switch RFID / SCAN |
| Trigger Key | Press / release | RFID reading, switch to Scan Engine |
