Chapter 1 Introduction 
1.1 About K220 
K220 is an efficient, flexible and convenient wireless barcode scanning device. K220 uses 
Bluetooth as the transmission medium, which can transmit data to the host over a long 
distance, allowing users to easily scan barcodes in different locations. K220 is committed 
to providing an excellent user experience, providing brand-new barcode scanning solutions 
for application scenarios such as industrial production, warehouse management, logistics 
and distribution, or retail, and easily responding to the scanning needs of different 
scenarios. 
 
1.2 About this manual 
The manual mainly introduces the system settings, communication settings, barcode 
parameter settings and setting methods of K220. By reading the setting barcode in the 
manual, you can enable the corresponding functions. The setting code marked with the 
words “default" represents the default setting of K220. The default settings provided by 
K220 are suitable for a variety of application scenarios. Users can use them out of the box, 
and generally do not need to set them separately.

3.2 Scan Mode  
 
3.2.1 Scan mode 
Level trigger mode:Press and holdthe scanbutton of the devicetostart reading the 
code, the code reading is successful or stop reading the code after releasing the button. 
Pulse trigger mode: Pressthe scanbutton of the devicetostart reading the code, and 
stop reading the code after the code reading is successful or the code reading duration 
is reached. 
Continuous mode: continuous decoding,press the device scanbutton to switch the 
code reading state and stop state. 
Sensing mode:The devicestarts reading the code after detecting the image change, 
and stops reading the code after the code reading is successful or the code reading 
duration is reached. 
Batch code reading mode: Press and hold the scan button of the device, the device 
starts reading the code, release the scan button to stop reading the code, as long as 
the scan button is not released, the device will continue to read the code. The device 
reads the code successfully, there is a successful prompt and outputs the barcode 
information. In the process of reading at a time, the same barcode is only allowed to 
be read once. 
Pre-aiming mode: After turning on the pre-aiming mode, the focusing laser is always 
on, indicating the current aiming position of the device. Press the scan button, the 
device starts to read the barcode, and stops reading the code when the scan button 
is released or the code reading is successful. 
 
Level trigger mode (default)

7.8 Data encapsulation 
Through the data encapsulation method, users can verify the data packet on the 
application side to ensure that complete and error-free data is obtained. 
It should be noted that after the data encapsulation is turned on, the user needs to 
actively parse the data packet to obtain the original data. 
 
There are two formats for data encapsulation: encapsulation format one and 
encapsulation format two 
package format one: [HEAD + LEN + TYPE] + DATA + [LRC] 
encapsulation format two: [HEAD + LEN + TYPE + CODE_ID] + DATA + [LRC] 
HEAD: Data header, fixed as 0x0200, double byte, big endian 
LEN: Barcode data (DATA) length, double bytes, big endian sequence, the value range is 0~65535 
TYPE: Encapsulation format, format one is 0x36, format two is: 0x3B, single byte 
CODE_ID: Barcode serial number, refer to Appendix-Barcode information 
DATA: Barcode DATA 
LRC: Check character, generated by the LRC check algorithm: LRC =0xFF ^ LEN ^ TYPE ^ DATA (^ 
stands for XOR operation), single byte
