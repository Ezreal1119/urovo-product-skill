## Page 2 — Scanning Performance and Physical Parameters

### Scanning Performance

| Field | Value |
| --- | --- |
| Performance | 1 GHz Dual-Core Processor |
| Image sensor | 1280 (horizontal) × 1080 (vertical) CMOS, 60 fps, 1.3 MP, CMOS |
| Light Source | Warm white LED, Red LED |
| Illumination | 650 nm laser, red crosshairs |
| Imager field of View | 38°H × 33°V nominal |
| Viewing angle | Roll 360°, Skew ±60°, Pitch ±60° |
| Reading accuracy | ≥3 mil |
| Minimum Print Contrast | 15% minimum reflective difference |
| Reading feedback | LED, vibration motors, and buzzers |

### Decode Capabilities

| Type | Symbologies |
| --- | --- |
| 2D Matrix | QR Code, PDF417, DataMatrix (ECC200), Micro QR, Chinese sensible code, Micro PDF417, Maxi Code, Aztec, etc. |
| Linear | UPC-A, UPC-E, EAN-8, EAN-13, ISBN, Code 128, GS1 128, ISBT 128, Code 39, Code 93, Code 11, Interleaved 2 of 5, Industrial 2 of 5, Matrix 25, Standard 25, Codabar, MSI/MSI PLESSEY, GS1 DataBar, etc. |

### Depth of Field

| Barcode | Range |
| --- | --- |
| Code 39 | 10 ~ 110 mm (5 mil) |
| EAN 13 | 15 ~ 155 mm (13 mil) |
| QR | 5 ~ 175 mm (20 mil) |
| DM (Data Matrix) | 15 ~ 115 mm (10 mil) |

### Physical Parameters

| Field | Value |
| --- | --- |
| Weight | Device 238 g, Base slot 216 g |
| External dimension | 98 mm × 72 mm × 186 mm |
| Communication interface | USB-HID, USB-CDC, RS232 |
| Prompt mode | Buzzer, LED indicator, vibrating motor |
