## Page 2 — Specifications

### Basic Characteristics

| Field | Value |
| --- | --- |
| Operation System | Compatible with Windows, Android and Linux systems |
| Processor | 32 bit ARM processor |
| Camera | 640 (H) × 480 (V) CMOS |
| Viewing Angle | Horizontal 31° |
| Skew / Pitch / Roll | Roll 360°, Skew ±55°, Pitch ±55° |

### Decode Ability

- Support mainstream 1D/2D barcodes, including EAN, QR, GS1, etc.
- Support barcodes on tags, monitors and mobile devices
- Support all payment codes, electronic tags, coupons, and color barcodes on the mobile devices

### Reading Distance

| Barcode | Range |
| --- | --- |
| EAN 13 | 4.0 ~ 20.0 cm (13 mil) |
| Code 128 | 4.5 ~ 25.0 cm (15 mil) |
| Code 39 | 4.5 ~ 9.5 cm (5 mil) |
| QR Code | 4.0 ~ 18 cm (15 mil) |

### Power and Physical

| Field | Value |
| --- | --- |
| Operating Voltage | USB 5 V |
| Operating Current | 125 mA, standby current 25 mA |
| Weight | 185 g (including USB cable) |
| Cable Length | 1.8 M |
| Dimension | 110 mm (L) × 71 mm (W) × 158 mm (H) |
| Material | ABS |

### Interfaces

| Field | Value |
| --- | --- |
| Interfaces | Support USB-HID, USB Virtual Serial Port, USB HID-KBW (default) |

### Environmental

| Field | Value |
| --- | --- |
| Operating Temperature | -20 °C ~ 60 °C |
| Storage Temperature | -40 °C ~ 70 °C |
| Humidity | 5% RH ~ 95% RH (non-condensing) |
| Vibration | 5 ~ 200 Hz, 10 G rms, 3-axes, 1.5 Hr |
| Drop | 1.5 M drops on concrete |
