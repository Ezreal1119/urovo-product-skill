# UROVO SE2030S 扫描引擎规格参数

> 原文：`Urovo-Scanner-SE2030S-Specs.pdf`（UROVO 优博讯）。本伴侣为忠实转写，供检索用；原始 PDF 保留在同一目录。

## 规格参数

| 项目 | 参数 |
| --- | --- |
| 图像分辨率 | 1280*1080 |
| 瞄准 | 红色十字激光 |
| 照明 | 白色 LED |
| 帧率 | 60 fps |
| 视场角 | 水平：38°，垂直：33° |
| 旋转角度 | 360° |
| 上下倾斜角度 | ±60° |
| 左右偏移角度 | ±60° |
| 符号对比度 | 最小打印对比度 20% |
| 最小解析度（1D） | ≥3 mil |

## 识读景深

| 条码类型 | 景深 |
| --- | --- |
| 13mil 100%UPC-A | 55–600 mm |
| 20mil QR Code | 30–530 mm |

## 支持码制

- **Linear:** UPC/EAN/JAN，GS1 Databar，Code 39，Code 128，Code 32，Code 93，Codabar/NW7，Interleaved 2 of 5，Code 2 of 5，Matrix 2 of 5，MSI，Telepen，Trioptic，China Post
- **2D Stacked:** PDF417，MicroPDF417，GS1 Composite
- **2D Matrix:** Aztec Code，Data Matrix，QR Code，MicroQR Code，Han Xin，MaxiCode
- **Postal:** Intelligent Mail Barcode，Postal-4i，Australian Post，British Post，Canadian Post，China Post，Japanese Post，Netherlands Post，Planet Code，Postnet
- **OCR:** OCR-A，OCR-B，E13B(MICR)
