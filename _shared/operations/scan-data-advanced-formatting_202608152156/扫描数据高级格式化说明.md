一、概要
本文主要描述扫描高级数据格式化功能设计与配置方法。高级数据格式允许根据满足特
定条件，对条码数据进行一个或多个组合规则操作，为用户提供数据传输前自定义数据格式。
特定条件包含：码制类型，条码固定内容，条码数据长度；操作规则包含：数据删除、截取、
替换、添加，分段输出等。可以创建任意数量的规则，相互依赖，操作顺序队列化，从而使
系统扫描服务能够满足几乎任何数据处理需求。
二、高级数据格式化成员定义
高级数据格式化功能通过规则、触发条件和操作实现。
1.成员名称
规则(Rule)
包含特定用户可定义触发操作条件和一个或多个处理数据操作方式的容器。系统可以同
时包含一个或多个用于处理扫描数据的高级数据格式化规则。
触发条件(Criteria)
用于执行处理操作的触发器。可以根据采集数据输入码制类型（即仅代码GS1-128数据）
和数据中的指定字符串（在数据字符串中的指定位置或指定长度）设置标准。获取的数据与
所有定义的条件不匹配，将不会触发操作。可以指定或允许任何所有受支持的条形码类型。
操作(Action)
用于分析、识别和处理扫描数据的一套程序。
支持操作类型：
光标移动
光标向前/后移动N个字符；移动到特定字符串前/后
数据修改
指定字符串替换为新字符串，去除开始位置、中间位置， n开始的m个字符，或者
结束n个字符
数据发送

2.1 条件(Criteria)
条码类型（Symbology）：匹配指定或允许任何所有受支持的条形码类型。条码类型
Symbology Id定义参考附录1。
字符串检测( specific string)：允许指定一个字符串，采集的条码数据中必须从指定

三、控制配置
1.开机后系统检测内部存储根目录下是否有 scanner_adfproperty.xml 文件，如果存在自动加
载解析配置。
2.通过API接口控制或更新配置
String ADF_ACTION = "com.ubx.advanceddataformat.adf.ACTION";
String ADF_SET_EXTRA = "com.ubx.advanceddataformat.adf.ADF_SET_EXTRA";
String EXTRA_IMPORT_CONFIGURATION_FILE =
"IMPORT_CONFIGURATION_FILE";
public static final String EXTRA_ADF_ENABLE = "ADF_ENABLE";
public static final String EXTRA_RULE_ENABLE = "RULE_ENABLE";
public static final String EXTRA_RULE_NAME = "RULE_NAME";
//广播action
Intent intent = new Intent(ADF_ACTION);
intent.putExtra(ADF_SET_EXTRA, true);
//可以通过接口通知系统加载指定使用特定目录下的配置文件(注意重新开机不加载该文件)
intent.putExtra(EXTRA_IMPORT_CONFIGURATION_FILE,
"sdcard/scanner_adfproperty_xxxx.xml");
//设置系统是否开始格式化处理功能
intent.putExtra(EXTRA_ADF_ENABLE, true);
//可以设置现有配置中规则名称为abcpdf417,配置项是否开启，
intent.putExtra(EXTRA_RULE_NAME,"abcpdf417");
intent.putExtra(EXTRA_RULE_ENABLE, false);
sendBroadcast(intent);

四、自定义配置 XML 文件
系统支持接口解析固定格式 XML 文件，识别对应的高级数据格式化 Rule,
Criteria ,Action,并应用到扫描数据处理过程。
配置示例1：输出Datamatrix条码数据中，第3位到第11位数据
Result: Data “1193160905021011063294” is formatted to “931609050”.
<?xml version="1.0" encoding="UTF-8"?>
<!-- 包含rule 个数，是否使能高级数据格式化 -->
<DataFormating Number="1" enable="true">
<!-- rule 名称，是否使能该规则 -->
<DataFormatingRule enable="true" name="dmfat">
<Criteria>
<!-- Datamatrix id Symbology.java -->
<CodeType symId="23">Datamatrix</CodeType>
<!-- 数据长度为0.不做检测 -->
<CodeLength>0</CodeLength>
</Criteria>
<Actions Number="2">
<!-- 2代码指令，跳过2个字符 -->
<Action index="2">2</Action>
<!-- 9代码指令send next，输出光标开始位置后的13个字符 -->
<Action length="13">9</Action>
</Actions>
</DataFormatingRule>
</DataFormating>
