# CT58 Accessories Brochure

> **Canonical original:** `CT58/accessories/default_202608151629/CT58-Accessories_Brochure_20231201.pdf`
> **Document date:** 2023-12-01 (from the source filename)
> **Language:** English
> **Scope:** Accessories for the CT58 Enterprise Mobile Computer (base CT58 model).

## Accessories Overview

- **Adaptor**, **USB Cable**, **Battery**
- **Single Charging Cradle**, **Trigger Handle**, **4-Slot Battery Charging Cradle**
- **Boot Case**, **Screen Protector**, **Hand Strap**

## Accessories List

### Adaptor

- Input: 100–240 V ~ 50/60 Hz, 0.6 A MAX
- Output: 5 V/2 A
- Port: USB Type-C

### USB Cable

- Supports charging and data transferring

### Battery

- Removable 3.85 V, 5000 mAh

### Single Charging Cradle

- Supports charging one device and one battery
- Supports CT58 with boot case
- LED charging status indicator
- Port: Type-C ×2 (charging and data transfer), LAN ×1

### Trigger Handle

- Efficient scanning with trigger button
- Comfortable grip

### 4-Slot Battery Charging Cradle

- Supports charging 4 batteries at the same time
- LED charging status indicator
- Interface: DC jack for charging
- Charging cradle adapter output: 12 V/2 A

### Boot Case

- Enhances the protection of the device

### Screen Protector

- Improves protection performance

### Hand Strap

- Convenient for mobile operation and carrying
- Used with the boot case
