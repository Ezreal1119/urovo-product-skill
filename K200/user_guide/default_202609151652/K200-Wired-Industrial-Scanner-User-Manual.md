Chapter 1 Introduction
1.1 About K200
The K200 is a portable scanning device based on image recognition technology that
quickly reads 1D and 2D barcodes. It is designed to provide accurate and reliable barcode
scanning solutions. The K200 features fast recognition speed and ease of use, supporting
the reading of mainstream 1D and 2D barcodes available on the market.
1.2 About this manual
This manual primarily introduces the system settings, communication settings,
barcode parameter settings, and setting methods for the K200. By scanning the setup
barcodes included in the manual, you can enable the corresponding functions. The
barcodes marked as "default" represent the default settings of the K200. The default
settings provided by the K200 are suitable for various application scenarios, allowing
users to use the device straight out of the box without needing additional configuration.

2.1 Setting method 1: Setting code
The scanner configures functions by reading a series of setting barcodes.
2.1.1 Direct Settings
The device sets the corresponding functions by directly reading the setting codes

2.1.2 Custom Settings
First, read the custom setting code, then read the numeric codes, and finally read the
setting terminator (semicolon: ;) to complete the configuration.
Each time a custom setting code or a complete setting code is read, the cache is
cleared before reading the terminator.
If an error occurs during the custom setting process, simply read the custom setting
code again to reset.

3.2 Scan Mode Settings
3.2.1 Scan Modes
Level Trigger Mode: Press and hold the device's scan button to start reading codes. It
stops reading codes upon a successful read or upon releasing the button.
Pulse Trigger Mode: Press the device's scan button to start reading codes. It stops
reading codes either upon a successful read or when the read duration ends.
Continuous Mode: Continuously decodes codes. Press the device's scan button to
toggle between the reading state and the stopped state.
Induction Mode: The device starts reading codes when it detects an image change. It
stops reading codes upon a successful read or when the read duration ends.
Batch Reading Mode: Press and hold the device's scan button to start reading codes.
Release the scan button to stop reading codes. The device will continue reading codes as
long as the scan button is pressed. A successful read will prompt and output the barcode
information. During a single reading process, the same barcode can only be read once.
Pre-Aim Mode: When pre-aim mode is enabled, the focus laser remains on,
indicating the device's current aiming position. Press the scan button to start reading the
barcode. The device stops reading codes when the scan button is released or upon a
successful read.

When keyboard emulation input is enabled, characters will be sent through the numeric keypad, ignoring
the national keyboard layout settings. This mode also requires setting the Code Page and Unicode
output. The Code Page determines the target language, and the Unicode output setting controls whether
the encoding method input to the host is Unicode or Code Page. ASCII characters in the range of 0x00 to
0x1F are output according to the settings of the "Control Character Output" function.
This method ensures that any character can be transmitted smoothly, but the output speed is slower
because simulating the necessary keystrokes for each character requires more operations.

as follows:
The character "A" is transmitted as "ALT MAKE" '0' '6' '5' "ALT BREAK".
The character "Ð" is transmitted as "ALT MAKE" '2' '0' '8' "ALT BREAK".
The character "B" is transmitted as "ALT MAKE" '0' '6' '6' "ALT BREAK".

Data format editing allows users to modify the device's output data. For example, users
can insert a string at a specified position. The device can support 4 sets of data formats,
and users need to specify which data format to use.

command in the data format editing commands. If "Data Format Mismatch Error Beep" is
enabled, the device will beep when the scanned barcode does not match the data format.
Each data format set can have a maximum length of 1024 characters. The data format
editing feature is disabled by default and needs to be manually enabled by the user.

7.8 Data Encapsulation
Through data encapsulation, users can verify data packets on the application side to
ensure that complete and correct data is received. It is important to note that after
enabling data encapsulation, users need to actively parse the data packets on the
application side to obtain the raw data.
There are two formats for data encapsulation: Encapsulation Format One and
Encapsulation Format Two.
Encapsulation Format One: [HEAD + LEN + TYPE] + DATA + [LRC]
Encapsulation Format Two: [HEAD + LEN + TYPE + CODE_ID] + DATA + [LRC]
HEAD: Data header, fixed at 0x0200, two bytes, big-endian.
LEN: Length of the barcode data (DATA), two bytes, big-endian, with a value range of 0 to 65535.
TYPE: Encapsulation format, 0x36 for Format One, 0x3B for Format Two, one byte.
DATA: Barcode data.
LRC: Check character generated by the LRC checksum algorithm: LRC = 0xFF ^ LEN ^ TYPE ^ DATA (^
represents XOR operation), one byte.
Disable Data Encapsulation (Default)
Enable Data Encapsulation, Using Encapsulation Format One
Enable Data Encapsulation, Using Encapsulation Format Two
